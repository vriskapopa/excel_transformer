# Customs Declaration Workspace

MVP под сценарий **18233** из архива заказчика (`materials/MVP_18233`).

## Открыть

```powershell
cd backend
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Сайт: http://127.0.0.1:8000/  
API: http://127.0.0.1:8000/docs

## Приёмка 18233

| Комплект | Позиции | Итоги vs эталон |
|---|---|---|
| 626-1 | 13 | совпадают (с округлением) |
| 626-2 | 17 | совпадают (с округлением) |

Экспорт заполняет копии готовых шаблонов заказчика:
- `18233 ИНВОЙС {kit}.xlsx`
- `18233 ПАКИНГ {kit}.xlsx`
- `18233 {kit} СПЕЦИФИКАЦИЯ С ЦВЕТАМИ.xlsx`

## Как проверить

1. Профиль **18233**
2. Загрузить 3 файла из `materials/MVP_18233/.../01_исходники/`
3. Проверить таблицу (13 или 17 строк), при необходимости поправить шапку/ячейки
4. **Сформировать Excel** и скачать 3 файла

Тесты: `python -m pytest tests -q` (21 passed), в т.ч. сравнение с эталоном.
